##### 1. Control de motores de corriente continua mediante puente H con Raspberry
Pi Pico W y C

Un motor de corriente continua no debe conectarse directamente a los GPIO de la
Raspberry Pi Pico W, ya que estos pines proporcionan señales de control y no
están diseñados para entregar la corriente necesaria para alimentar un motor.

Para controlar los motores se utiliza un puente H o un módulo driver de motores.
Este dispositivo se coloca entre la Raspberry Pi Pico W y los motores. La Pico W
envía las señales de control al puente H y este se encarga de manejar la corriente
que necesitan los motores.

Una de las principales funciones del puente H es permitir cambiar el sentido de
giro del motor. Dependiendo de las señales recibidas en sus entradas, el motor
puede avanzar o retroceder.

Para el Robot Sumo esto es fundamental porque se necesitan diferentes
movimientos para competir: avanzar hacia el oponente, retroceder, girar y realizar
correcciones de dirección.

La conexión exacta dependerá del modelo de puente H que utilice el equipo. Por
este motivo, antes de realizar el circuito definitivo se deberá consultar la hoja de
datos del driver correspondiente.

La programación se realizará en C/C++ utilizando el Raspberry Pi Pico SDK, sin
utilizar Arduino. El SDK proporciona funciones para controlar los GPIO y el PWM
de la Raspberry Pi Pico.

##### 2. PWM y su integración con el puente H

PWM significa Pulse Width Modulation, o modulación por ancho de pulso. Es una
técnica que permite controlar una salida mediante una señal que alterna
rápidamente entre un nivel alto y uno bajo.

El parámetro principal es el duty cycle, que representa el porcentaje del período
durante el cual la señal permanece en nivel alto.

Por ejemplo, de manera simplificada:

- 0 % de duty cycle: salida apagada.
- 50 % de duty cycle: señal activa durante aproximadamente la mitad del período.
- 100 % de duty cycle: salida completamente activa.

En el Robot Sumo, el PWM puede utilizarse para regular la velocidad de los
motores. La Raspberry Pi Pico W genera la señal PWM y la envía a la entrada
correspondiente del driver o puente H.

El RP2040, microcontrolador utilizado por la Pico W, posee hardware específico
para generar PWM. El Pico C/C++ SDK proporciona funciones para configurar y
controlar estas salidas.

El PWM también puede utilizarse para que los dos motores trabajen a velocidades
diferentes. Esto permite realizar giros y correcciones de dirección. Por ejemplo, si
un motor gira más rápido que el otro, el robot puede cambiar su trayectoria.

La frecuencia y el duty cycle deberán ajustarse mediante pruebas prácticas,
teniendo en cuenta las características de los motores y del puente H.

##### 3. Utilización del Wi-Fi de la Raspberry Pi Pico W

La Raspberry Pi Pico W posee conectividad Wi-Fi integrada, por lo que no es
necesario agregar un módulo Wi-Fi externo.

La conectividad inalámbrica utiliza el chip CYW43439 y puede utilizarse mediante
las herramientas y librerías proporcionadas por el Raspberry Pi Pico C/C++ SDK.

Para utilizar el Wi-Fi desde un programa en C/C++ se deben configurar
correctamente las librerías correspondientes y los datos de la red a la que se
desea conectar.

El SDK utiliza componentes relacionados con CYW43 y la pila de red lwIP para
proporcionar las funciones de comunicación.

En el Robot Sumo, el Wi-Fi podría utilizarse para establecer comunicación entre la
Raspberry Pi Pico W y otro dispositivo. Por ejemplo, podría permitir enviar
comandos al robot, controlar determinadas funciones o intercambiar información.

Esta parte todavía no se encuentra implementada. Primero se deberá comprobar
el funcionamiento básico de la conexión Wi-Fi y posteriormente integrarla al
programa principal del robot.

##### 4. Problemas que pueden aparecer durante el proyecto

Durante la construcción del Robot Sumo pueden aparecer problemas eléctricos,
mecánicos y de programación.

En la parte eléctrica pueden producirse conexiones incorrectas, problemas de
alimentación, caída de tensión o un consumo de corriente mayor al esperado por
los motores.

También se debe tener en cuenta que la Raspberry Pi Pico W trabaja con lógica
de 3,3 V, por lo que las entradas y salidas del circuito deben ser compatibles con
este nivel.

En los motores pueden aparecer diferencias de velocidad entre uno y otro. Esto
podría provocar que el robot no avance en línea recta. Para solucionarlo se puede
ajustar el PWM de cada motor mediante el programa.

En el puente H pueden producirse errores de conexión o configuraciones
incorrectas de sus entradas. Por eso será necesario consultar la hoja de datos del
modelo utilizado antes de realizar la conexión definitiva.

En la programación pueden aparecer errores al configurar GPIO, PWM, motores o
Wi-Fi. También pueden aparecer problemas de compilación o configuración del
Raspberry Pi Pico SDK.

En la comunicación Wi-Fi pueden surgir problemas para conectarse a la red o para
establecer correctamente la comunicación entre dispositivos.

En la parte mecánica pueden aparecer problemas relacionados con el chasis, el
peso, la posición de los motores, el agarre de las ruedas o la estabilidad del robot.

Para reducir estos problemas se propone realizar las pruebas por etapas. Primero
se comprobará cada componente individualmente, después se probarán los
motores y el puente H, luego el PWM y finalmente se integrará el Wi-Fi y el resto
del sistema.

##### Aplicación de la investigación al Robot Sumo

La investigación realizada permite establecer una primera estructura del sistema:

Raspberry Pi Pico W → señales GPIO/PWM → puente H → motores →
movimiento del Robot Sumo

La Pico W será el elemento encargado de ejecutar el programa. El puente H
permitirá manejar los motores y controlar su sentido de giro. El PWM permitirá
regular su velocidad y realizar diferentes movimientos. Finalmente, el Wi-Fi podrá
utilizarse para establecer comunicación inalámbrica con el robot.

El chasis previsto para el proyecto será el de un kit de auto de 3 ruedas. La
conexión definitiva de los componentes deberá realizarse después de identificar
exactamente el puente H y los motores disponibles.
